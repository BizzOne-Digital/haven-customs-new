# Haven Customs — Product Image Brief

One image per service, so the Services page no longer repeats the same photo.

## How to deliver

1. **File name = product slug** (left column below), e.g. `nano-ceramic-tint.webp`.
2. Put the files in **`public/images/products/`**.
3. **Format:** WebP (preferred) or JPG/PNG. **Size:** 1600 × 900 px (16:9). Keep each file under ~300 KB.
4. Commit and push. The site picks them up automatically on the next deploy. No code changes are needed.

A product without its own image keeps showing its category image, so images can be added a few at a time.

## Style (use for every image)

> Single photorealistic premium automotive photo. Dark graphite/black workshop or studio, glossy reflective floor, restrained racing-red accent lighting. Black-gloved technician hands where a service is being performed. Shallow depth of field, cinematic contrast. **No text, no logos, no brand names, no watermarks, no UI, no collages.** 16:9.

Rules:
- Do **not** show recognisable brand logos (XPEL, EVER, AzDome, Lingdu, etc.). Dashcams and devices should be generic.
- Keep the same car family (graphite/black sports sedans and SUVs) so the grid looks consistent.
- Images are illustrative. They must not look like a specific customer's car or a verified product model.
